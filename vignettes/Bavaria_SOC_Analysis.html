1. Introduction and Background

Soil Organic Carbon (OC) plays a critical role in agricultural productivity and regional climate mitigation strategies. Soil research is still reliant on traditional point-based sampling, but it does not provide the continuous coverage required for spatial decision-making.
Geostatistical methods, such as Inverse Distance Weighting (IDW) and Kriging, address this by modelling the spatial autocorrelation of soil point observations to predict values at unsampled locations.

This vignette presents a reproducible geostatistical data pipeline evaluating OC distribution across the state of Bavaria, Germany. Using a dataset obtained from the official LUCAS 2018 Topsoil Survey compiled by the European Soil Data Centre (ESDAC), this study shows how SoilGeoStats package simplifies spatial data ingestion, exploratory statistics, and continuous grid surface interpolation within an object-oriented R framework using S3 method dispatching.
SoilGeoStats will be useful to spatial data analysts, environmental scientists, soil ecologists, and researchers who work with soil point datasets and need a quick, reproducible pipeline to clip, validate, and carry out geostatistical interpolation.

2. Data Description

The LUCAS 2018 Topsoil dataset used in this work contains soil properties such as pH, organic carbon content, phosphorus, potassium, and nitrogen, covering the European Union and the United Kingdom.
This dataset originally consisted of 18,984 samples, taken from 0-20 cm depth in a CSV file.

The study workflow showcases standard GIS methods upgraded into an object-oriented R programming framework utilizing S3 method dispatching.

3.1. Ingestion, Validation, and Spatial Clipping

The first stage of the analysis pipeline ingests unprojected WGS84 point records and intersects them against a regional vector boundary shapefile of Bavaria (EPSG: 25832) obtained from GADM, stored directly within the package’s inst/extdata directory. The function automatically resolves coordinate mismatches, clips observations to the study area, and appends projected UTM coordinates.

# Ingest and spatially process the dataset using system file paths
soil_data_raw <- load_and_validate_data(
    file_path = system.file("extdata", "soil_data/LUCAS-SOIL-2018.csv", package = "SoilGeoStats"), # file path to soil data 
    x_col = "TH_LONG", # X coordinate column
    y_col = "TH_LAT", # Y coordinate column
    target_col = "OC", # the variable to be modelled
    covariate_cols = c("N", "Elev"), # covariate variables for regression kriging
    shape_path = system.file("extdata", "shape_file/Bav_Boundary.shp", package = "SoilGeoStats") # file path to boundary shapefile
)
#> Warning: attribute variables are assumed to be spatially constant throughout all geometries

# Filter to essential columns only

Column Definitions:

OC (Organic Carbon Content): the primary target variable,representing the mass fraction of organic carbon in the topsoil (g/kg).

N (Nitrogen): an environmental covariate representing the total nitrogen content (g/kg), highly correlated with organic matter accumulation.

Elev (Elevation): A topographic covariate representing altitude above sea level (meters).

geometry (Spatial Features): Point geometries in the ETRS89 / UTM zone 32N grid system.

3.2. Exploratory Spatial Data Analysis

Before interpolating, a distance metrics alongside basic summary statistics (such as mean, median, variance) are calculated to analyze point spacing bounds and global distribution skewness.

# Execute exploratory spatial data analysis of target variable (OC)
eda_metrics <- exploratory_data_analysis(spatial_data = soil_data_clipped, target_col = "OC")

# Display compiled summary metrics
cat("Total Observations Inside Mask  :", eda_metrics$total_points, "points\n")
#> Total Observations Inside Mask  : 124 points
cat("Minimum Point Spacing Interval  :", round(eda_metrics$minimum_sampling_interval_meters / 1000, 2), "km\n")
#> Minimum Point Spacing Interval  : 2.83 km
cat("Maximum Study Extent Diameter   :", round(eda_metrics$maximum_sampling_interval_meters / 1000, 2), "km\n")
#> Maximum Study Extent Diameter   : 361.43 km
cat("Sample Mean of Target Column:", eda_metrics$variable_mean, "\n")
#> Sample Mean of Target Column: 32.99839
cat("Sample Median of Target Column:", eda_metrics$variable_median, "\n")
#> Sample Median of Target Column: 29.45
cat("Sample Variance of Target Column:", eda_metrics$variable_variance, "\n")
#> Sample Variance of Target Column: 470.3382

Statistical Significance of Results:

  • Total Observations (total_points): Represents the observation sample size available within the geographic region.

  • Minimum Point Spacing Interval (minimum_sampling_interval_meters): Signifies the absolute finest spatial resolution of the raw data collection grid. This metric tells us how close the nearest neighbor points are.

  • Maximum Study Extent Diameter (maximum_sampling_interval_meters): Measures the absolute maximum geographic distance stretching across the study polygon. It is critical for constraining interpolation search radii.

  • Sample Mean (variable_mean): This provides the global mathematical baseline of Topsoil Organic Carbon across Bavaria.

  • Sample Median (variable_median): This identifies the exact midpoint of the data distribution. Comparing the mean directly to the median allows us to detect statistical skewness.
    If the mean is significantly higher than the median, it indicates a right-skewed distribution, meaning the landscape has localized “hotspots” of high carbon storage among lower baseline agricultural values.

  • Sample Variance (variable_variance): Measures the global dispersion and heterogeneity of the Soil Organic Carbon data. Higher variance values signal an environmentally complex region with significant localized shifts, highlighting why advanced geostatistical modeling (like Regression Kriging) is necessary over simple averages.

3.3. Spatial Interpolation (S3 Object Construction)

Two interpolation approaches - deterministic Inverse Distance Weighting (IDW) and hybrid Regression Krigging (RK) model incorporating Nitrogen and Elevation covariates, are compared.
Both engines return the custom S3 spatial_grid class.

# 1. Deterministic Inverse Distance Weighting Interpolation
idw_grid_obj <- interpolate_idw_surface(spatial_data = soil_data_clipped, target_col = "OC", power = 2.0)

# 2. Multi-Variable Regression Kriging (Using Nitrogen and Elevation Covariates)
rk_grid_obj  <- interpolate_regression_kriging(spatial_data = soil_data_clipped, 
                                                target_col = "OC", 
                                                covariate_cols = c("N", "Elev"))

4. Discussion of Results

The exploratory spatial data analysis revealed an asymmetry between the sample mean (33.00 g/kg) and median (29.45 g/kg), indicating a right-skewed distribution with localized high-value OC hotspots across Bavaria.

Evaluating the Leave-One-Out Cross-Validation metrics demonstrates a significant performance difference between the two interpolation models:

  • Inverse Distance Weighting (IDW) produced a Root Mean Square Error (RMSE) of 19.94 g/kg. IDW relies solely on spatial proximity,therefore it struggles to capture non-linear local shifts in heterogeneous terrain like Bavaria.

  • Regression Kriging (RK) drastically reduced prediction error to an RMSE of 5.85 g/kg (that is a 70% reduction in prediction error).

Combining environmental trend relationships (elevation gradients and total nitrogen) with residual kriging, Regression Kriging accounts for deterministic environmental drivers alongside spatial autocorrelation, yielding a superior continuous estimation surface for topsoil organic carbon.
