Geostatistical Modelling of Soil Organic Carbon in Bavaria

Introduction and Background

This vignette presents a reproducible geostatistical data pipeline evaluating Soil Organic Carbon (OC) distribution across Bavaria, Germany. Using a dataset obtained from the official LUCAS 2018 Topsoil data compiled by the European Soil Data Centre (ESDAC), this package will be useful to spatial data analysts, environmental scientists, soil ecologists, and researchers who work with soil point datasets and need a quick, reproducible pipeline to clip, validate, and carry out geostatistical interpolation.

The study workflow showcases standard GIS methods upgraded into an object-oriented R programming framework utilizing S3 method dispatching.

library(SoilGeoStats)
library(sf)
library(ggplot2)

I. Ingestion, Validation, and Spatial Clipping

The first stage of the analysis pipeline ingests unprojected WGS84 point records and matches them against a regional vector boundary shapefile of Bavaria (EPSG: 25832) obtained from GADM. The function automatically resolves coordinate mismatches, carries out a point-in-polygon intersection clip, and appends the resulting coordinate values.

# Ingest and spatially process the dataset using system file paths
soil_data_raw <- load_and_validate_data()
#> Warning: attribute variables are assumed to be spatially constant throughout all geometries

# Filter to essential columns only
soil_data_clipped <- dplyr::select(soil_data_raw, OC, N, Elev, geometry)

Column Definitions:

OC (Organic Carbon Content): the primary target variable,representing the mass fraction of organic carbon in the topsoil (g/kg).

N (Nitrogen): an environmental covariate representing the total nitrogen content (g/kg), highly correlated with organic matter accumulation.

Elev (Elevation): A topographic covariate representing altitude above sea level (meters).

geometry (Spatial Features): The metric coordinate point layouts in the ETRS89 / UTM zone 32N grid system.

II. Exploratory Spatial Data Analysis

Before running interpolations, a spatial distance analysis is executed to compute minimum and maximum point-pair bounds alongside basic variable summary metrics (such as mean, median, variance).

# Execute spatial distance metric profiling
eda_metrics <- calculate_spatial_distances(spatial_data = soil_data_clipped, target_col = "OC")

# Display compiled summary metrics
cat("Total Observations Inside Mask  :", eda_metrics$total_points, "points\n")
#> Total Observations Inside Mask  : 124 points
cat("Minimum Point Spacing Interval  :", round(eda_metrics$minimum_sampling_interval_meters / 1000, 2), "km\n")
#> Minimum Point Spacing Interval  : 2.83 km
cat("Maximum Study Extent Diameter   :", round(eda_metrics$maximum_sampling_interval_meters / 1000, 2), "km\n")
#> Maximum Study Extent Diameter   : 361.43 km
cat("Sample Mean of Target Column:", eda_metrics$variable_mean, "\n")
#> Sample Mean of Target Column: 32.99839
cat("Sample Median of Target Column:", eda_metrics$variable_median, "\n")
#> Sample Median of Target Column: 29.45
cat("Sample Variance of Target Column:", eda_metrics$variable_variance, "\n")
#> Sample Variance of Target Column: 470.3382

Statistical Significance of Results:

  • Total Observations (total_points): Represents the observation sample size available within the geographic region. A robust point count provides the data density required to build statistically sound interpolation weights.

  • Minimum Point Spacing Interval (minimum_sampling_interval_meters): Signifies the absolute finest spatial resolution of the raw data collection grid. This metric tells us how close the nearest neighbor points are.

  • Maximum Study Extent Diameter (maximum_sampling_interval_meters): Measures the absolute maximum geographic distance stretching across the study polygon. It is critical for constraining interpolation search radii.

  • Sample Mean (variable_mean): This provides the global mathematical baseline of Topsoil Organic Carbon across Bavaria.

  • Sample Median (variable_median): This identifies the exact midpoint of the data distribution. Comparing the mean directly to the median allows us to detect statistical skewness. If the mean is significantly higher than the median, it indicates a right-skewed distribution, meaning the landscape has localized “hotspots” of high carbon storage among lower baseline agricultural values.

  • Sample Variance (variable_variance): Measures the global dispersion and heterogeneity of the Soil Organic Carbon data. Higher variance values signal an environmentally complex region with significant localized shifts, highlighting why advanced geostatistical modeling (like Regression Kriging) is necessary over simple averages.

III. Spatial Interpolation (S3 Object Construction)

The deterministic and hybrid geostatistical modeling engines are executed. The functions automatically output instances of the custom S3 spatial_grid class.

# 1. Deterministic Inverse Distance Weighting Interpolation
idw_grid_obj <- interpolate_idw_surface(spatial_data = soil_data_clipped, target_col = "OC", power = 2.0)

# 2. Multi-Variable Regression Kriging (Using Nitrogen and Elevation Covariates)
rk_grid_obj  <- interpolate_regression_kriging(spatial_data = soil_data_clipped, 
                                                target_col = "OC", 
                                                covariate_cols = c("N", "Elev"))

V. Cartographic Visualizations

Finally, the custom S3 plot() method is explored. By integrating the study region’s polygon file path directly into the generic function, it automatically generates continuous map tile surfaces clipped cleanly to study region.

# Extract internal shape path for vector outlines
bavaria_mask <- sf::st_read(system.file("extdata", "shape_file/Bav_Boundary.shp", package = "SoilGeoStats"), quiet = TRUE)

# Generate custom continuous map objects
map_idw <- plot(idw_grid_obj, boundary_data = bavaria_mask) #IDW surface
map_rk  <- plot(rk_grid_obj, boundary_data = bavaria_mask) #Regression Krigging Surface

# Render the final cartographic surfaces
print(map_idw)

print(map_rk)
